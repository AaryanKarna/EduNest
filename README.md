# EduNest
EduNest is a modern educational platform designed for university 
students in Nepal. It replaces basic LMS systems with a smarter, 
AI-assisted learning experience.

## Core Features
**For Students**
- Access enrolled courses and materials
- AI study assistant per course
- Exam preparation and assignment help
- Discussion forums and notifications

**For Teachers**  
- Create and manage courses
- Upload study materials
- Enroll students
- Track submissions and grade assignments

## Technology
React, TypeScript, Tailwind CSS, Express, Node.js

## Getting Started
npm install
npm run dev
